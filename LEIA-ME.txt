CLOUDCONVENIOS V8.4.2 — REFRESH TOKEN

Esta correção:
- remove sessões antigas ou inválidas do navegador;
- não chama refreshSession manualmente na página de usuários;
- evita concorrência na rotação do refresh token;
- direciona o usuário ao login quando o token não existe mais;
- preserva a URL e a chave pública atualmente configuradas no projeto;
- não altera banco, SQL ou variáveis do Cloudflare.

COMO INSTALAR
1. Extraia este ZIP.
2. Abra o GitHub Desktop no repositório CloudConvenios.
3. Execute CORRIGIR-REFRESH-TOKEN-V8.4.2.bat.
4. Selecione a pasta aberta por Show in Explorer.
5. Caso o envio automático não termine, faça:
   - Summary: Corrigir refresh token V8.4.2
   - Commit to main
   - Push origin
6. Aguarde o deploy verde no Cloudflare.
7. Feche todas as abas do CloudConvenios.
8. Abra o site e faça login novamente.

IMPORTANTE
A tabela public.usuarios não é a lista de contas de autenticação.
No Supabase:
- clique no ícone de cadeado Authentication e abra Users; ou
- no Table Editor, troque o schema public para auth e abra users.
