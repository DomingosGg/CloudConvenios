# Correção visual 7.1

Esta versão incorpora o CSS completo dentro do `index.html` e também mantém `css/style.css`.

## Publicação

1. Extraia o ZIP.
2. No GitHub, apague os arquivos antigos do repositório ou substitua todos.
3. Envie **o conteúdo interno** da pasta extraída para a raiz do repositório.
4. Confirme que aparecem na raiz: `index.html`, `css`, `js`, `netlify`, `supabase` e `netlify.toml`.
5. Aguarde o deploy automático do Netlify.
6. Abra o site com `Ctrl + F5` ou em janela anônima.

O CSS incorporado impede que a tela apareça como texto simples mesmo quando o arquivo externo não for carregado.
