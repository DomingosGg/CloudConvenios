# Variáveis de ambiente — referência

## Públicas no navegador

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY` ou `SUPABASE_ANON_KEY`

## Segredos das Pages Functions

- `SUPABASE_SECRET_KEY` ou `SUPABASE_SERVICE_ROLE_KEY`
- `EXPORT_CRON_SECRET`

As chaves secretas devem ser cadastradas somente no painel do Cloudflare Pages. Não salve esses valores em arquivos versionados.
